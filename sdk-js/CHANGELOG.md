# Changelog

All notable changes to `@cortexops/sdk` are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the package uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - Unreleased

First release of the TypeScript / JavaScript SDK.

### Added

- `CortexTracer`: `wrap()`, `traceNode()`, `recordToolCall()`, `startTrace()` / `runTraced()`, in-memory trace buffer (`lastTrace()`, `traces()`), and non-blocking uploads to `POST /v1/traces` with `flush()` / `shutdown()`.
- Prompt version tagging with `setPrompt()`, `clearPrompt()` and `usePrompt()`, isolated per async context.
- Head sampling (`sampleRate`, `CORTEXOPS_SAMPLE_RATE`) that still captures failed runs (`sampleErrors`).
- Configuration resolution in the order explicit option, then `CORTEXOPS_*` environment variables, then `~/.cortexops/credentials`.
- Integrations, using structural types with no framework dependencies:
  - Vercel AI SDK 5 / 6 / 7: `wrapGenerateText`, `wrapStreamText` and `cortexopsMiddleware`.
  - LangGraph.js: `invoke` and `stream`.
  - OpenAI Agents SDK: `run` and `agent.run`, including streaming.
  - Mastra: `generate` and `stream`.
  - `detectFramework()`, used by `tracer.wrap()` for auto-detection.
- `EvalSuite.run()` with the Python SDK's golden YAML format, metrics, pass/fail rules, p50/p95 and `fail_on` expressions (`task_completion`, `tool_accuracy`, `pass_rate`). Parity is verified against fixtures generated by the Python SDK.
- `evalGate()` for Vitest, Jest and `node:test`, the counterpart of `@cortexops.eval_gate`.
- `cortexops-js eval run` CLI:
  - repeatable `--fail-on` (default `pass_rate < 1.0`)
  - `--output-json`, `--summary-md` and `--junit-xml` in the Python CLI's report formats, plus `--output` for the raw summary
  - automatic `GITHUB_STEP_SUMMARY` append and `--push`
  - exit codes 0 / 1 / 2
- `CortexClient`: `pushTrace`, `getTrace`, `listTraces`, `pushEval`, `getEval`, `listRuns`, `diff`, `quota`.
- JSON Schema for the golden dataset format (`schema/golden-dataset.v1.schema.json`).
- ESM and CommonJS builds with type definitions; Node.js 18 or newer.
