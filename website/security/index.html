Security

Last updated: July 5, 2026

API keys

  • Keys use cxo- prefix with 256-bit entropy; only SHA-256 hashes are stored.
  • Rotate or revoke keys instantly from the dashboard.
  • Production key creation requires authentication or admin internal key; first keys use rate-limited bootstrap.

Transport & secrets

  • All endpoints served over HTTPS (TLS 1.2+).
  • JWT secrets and internal keys must be set in production — the API refuses to start with defaults.
  • Dashboard sessions use short-lived JWTs (1 hour); browser stores API key in localStorage for refresh.

Data protection

  • PII redaction on ingest (email, card, SSN, phone patterns).
  • PostgreSQL in production; SQLite disabled in production deploys.
  • Containers run as non-root user.

Report a vulnerability

Email contact@getcortexops.com with details. We aim to respond within 48 hours.
