Privacy Policy

Last updated: July 5, 2026

CortexOps (“we”, “us”) provides reliability infrastructure for AI agents. This policy describes how we handle information when you use getcortexops.com, app.getcortexops.com, docs.getcortexops.com, and api.getcortexops.com.

Information we collect

  • Account data: project name, email (for Pro billing), and API key metadata (hashed — we never store raw keys after creation).
  • Service data: traces, eval results, datasets, and prompts you send via the SDK or API.
  • Payment data: processed by PayPal/Stripe; we do not store full card numbers.
  • Usage logs: request timestamps, IP addresses, and error logs for security and reliability.

How we use data

We use your data to operate the service, provide dashboards, send billing receipts, detect abuse, and improve reliability. We do not sell your data.

PII in traces

The API redacts common PII patterns (email, card numbers, SSN, phone) before storage. You are responsible for not sending regulated data you are not authorized to process.

Retention

Free tier: 7-day trace retention. Pro tier: 90-day trace retention. You may request deletion by contacting us.
